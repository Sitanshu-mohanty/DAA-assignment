# Test Cases

## Test Case 1 - 3-Sum Exists

Input:
```text
6
2 4 7 9 11 15
3
22
```

Expected:
```text
A set of 3 integers with sum 22 exists.
```

## Test Case 2 - No Solution

Input:
```text
5
1 3 5 7 9
3
20
```

Expected:
```text
No solution found.
```

## Test Case 3 - 4-Sum Exists

Input:
```text
7
1 2 4 6 8 10 12
4
20
```

Expected:
```text
A set of 4 integers with sum 20 exists.
```

One valid combination is `2 + 4 + 6 + 8 = 20`.

## Test Case 4 - Negative Values

Input:
```text
6
-8 -4 -1 3 6 10
3
1
```

Expected:
```text
A set of 3 integers with sum 1 exists.
```

One valid combination is `-8 + -1 + 10 = 1`.

## Test Case 5 - k Equals 2

Input:
```text
5
2 5 8 11 14
2
19
```

Expected:
```text
A set of 2 integers with sum 19 exists.
```

One valid combination is `5 + 14 = 19`.
